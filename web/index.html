Names, recipes and station capacities come with the page, from game build 3674.

If your game is newer, click the chip and choose its en.json; it is remembered in this browser and wins over the built-in text.

Where is my save?

In the folder picker, paste the Windows path into File name and press Enter. Choose the Big Ambitions folder; the page finds the newest save across the company folders inside it, whose generated names cannot be told apart by eye.

Save folder · Windows
%USERPROFILE%\AppData\LocalLow\Hovgaard Games\Big Ambitions\SaveGames\Big Ambitions

On macOS: ~/Library/Application Support/Hovgaard Games/Big Ambitions/SaveGames/Big Ambitions

Game text · en.json lives here, only needed if your game is newer than the built-in text
C:\Program Files (x86)\Steam\steamapps\common\Big Ambitions\Big Ambitions_Data\StreamingAssets\locale

The game autosaves every five minutes. Your browser may call folder access an "upload" or ask to "let this site view files"; the save stays on your computer. Checked on game build 3674; the Python runtime the page needs is about 6 MB, fetched once and cached. Visits are counted by Cloudflare's cookieless analytics; nothing about your save or company is in that count.

The page only reads your save files.
