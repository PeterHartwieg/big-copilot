# RLO companion contract v1

These are byte-for-byte copies of `schema.json`, `ready.json` and `partial.json`
from RLO's `contracts/companion/v1/`. The fixtures are synthetic and produced by
RLO's EconomyCheck using its production reporting code. Do not edit the copies to
make a consumer test pass; change the producer, regenerate, review and copy them.

See [the integration guide](../../docs/rlo-companion.md) for freshness, supported
capabilities, limits and the cross-repository check command.
